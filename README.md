One funny line: "The Wi-Fi went down, so my family had to talk to each other, and nobody knew the password to that either." — the Wi-Fi dies, the family is forced to talk, and the punch reframes the conversation itself as something locked behind a password. Entry for make.fun's "The One-Line Laugh" bounty ($5 top 3). The program writes the line to /output/entry.txt.

## Run it

```sh
node main.ts
```
